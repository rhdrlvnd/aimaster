# 정량 목표 — 선택 결과 및 후보 검토 이력

- 작성일: 2026-10-13
- 목적: 정량 목표 후보의 검토 이력과 선택 결과 관리

## 선택 결과 — 2026-10-13

사용자는 1번, 2·3번 통합, 6번, 14번을 선택했다. Task 1·2와 기획서에 반영했다.

1. 체크리스트 작성 시간 단축률
2. 인수인계 소요 시간 단축률
3. 전임자에게 직접 확인해야 하는 질문 감소율
4. 기한 내 인수인계 완료율

목표 수치는 작성 시간 50% 이상 단축, 인수인계 소요 시간 20% 이상 단축, 직접 확인 질문 40% 이상 감소, 기한 내 완료율 90% 이상으로 정했다. 현재 실적이 아닌 개발 후 검증할 목표값이다. 2번은 경과 업무일 수로 측정하며 실제 투입 시간과 합산하지 않는다. 사용자 요청에 따라 현재 수준의 예상값은 120분·10업무일·직접 확인 질문 20건·기한 내 완료율 70%로 설정했다. 실제 평균 통계가 아닌 기획상 가정이며, 예상 기준 목표는 1시간 이하·8업무일 이하·12건 이하·90% 이상이다. 아래 후보·조합 제안은 선택 이전의 검토 이력이다.

## 1. 시간 지표의 구분

체크리스트 작성 시간은 전임자의 준비 작업 일부다. 전체 인수인계 소요 기간은 시작부터 합의한 업무의 인수 완료까지의 경과 기간이며, 참여자의 일정·병행 업무·숙련도에도 영향을 받는다. 전임자와 후임자가 실제로 투입한 시간의 합은 별도 지표다. 기간과 투입 시간을 섞지 않는다.

완료 기준은 완료 버튼 클릭만으로 두지 않고 사전에 정한 업무 설명·실습 확인 등의 기준을 두어야 한다. 평가용 업무로 진행한 모의 실험은 실제 현장 인수인계 기간 단축으로 표현하지 않는다.

현재 평가 설계는 [Task 2](TASK_02_SUBMISSION.md)를 따른다. 아래 미선택 후보는 추가 KPI나 개발 범위를 의미하지 않는다.

## 2. 후보 — 선택 이전 이력

| 번호 | 지표 | 측정 방법 | 평가 조건 |
|---|---|---|---|
| 1 | 체크리스트 작성 시간 단축률 | 문서 확인 시작부터 사용 가능한 체크리스트 확정까지 수작업과 AI 활용 시간을 비교. 생성 대기·검토·수정 포함 | 동일한 범위와 품질 기준으로 실험 가능 |
| 2 | 인수인계 전체 소요 기간 단축률 | 시작부터 사전에 정한 인수 완료 기준 충족까지 업무일 수 비교 | 유사한 실제 인수인계 사례·참여자 필요. 일정표 길이를 성과로 사용하지 않음 |
| 3 | 인수인계 총 투입 시간 감소율 | 정리·설명·질문·검토 등 전임자와 후임자가 실제 투입한 시간을 합산해 비교 | 시간 기록 필요. 경과 기간과 구분 |
| 4 | 필요한 업무 정보 확인 시간 단축률 | 질문을 받은 시점부터 근거가 맞는 답을 확인할 때까지 직접 문서 검색과 AI 사용을 비교 | 같은 난이도의 질문·정답·근거 필요. 빠른 오답을 성공으로 계산하지 않음 |
| 5 | 전임자의 추가 설명 시간 감소율 | 인수인계 중 전임자가 질문을 받고 답변·설명하는 데 쓴 시간 비교 | 실제 또는 역할을 나눈 모의 평가 필요. 이해 수준이 낮아진 채 질문만 줄지 않았는지 확인 |
| 6 | 전임자에게 직접 확인해야 하는 질문 비율 | 전체 평가 질문 중 AI 사용 후 전임자 추가 답변이 필요한 질문의 비율을 기존 방식과 비교 | 실제 후임자 평가가 적합. 혼자 평가하면 사람 문의 필요 비율의 대리 평가라고 명시 |
| 7 | 체크리스트 필수 업무 포함률 | 사전 정의한 필수 업무 중 AI 초안에 올바르게 포함된 업무 수 ÷ 필수 업무 수 | 사람 수정 전 초안과 최종 결과 구분 |
| 8 | 체크리스트 수정 부담 | 동일 문서에서 수작업 또는 기본 생성 결과와 비교해 최종 확정 전 추가·삭제·수정한 항목 수를 기록 | 업무 구분 단위를 동일하게 유지. 고도화 기능 추가를 뜻하지 않음 |
| 9 | 문서 기반 질문 정답률 | 정답과 근거가 맞는 답변 수 ÷ 평가 질문 수 | 답 없는 질문 포함. 답변 거절의 적절성은 유형별로도 확인 |
| 10 | 일정 작성 시간 단축률 | 확정 체크리스트로 일정 작성 시작부터 유효한 일정 확정까지 수작업과 AI 활용 비교 | 동일 기간·선후관계·가용 시간 조건, 검토·수정 포함 |
| 11 | 일정 재조정 시간 단축률 | 같은 지연 상황에서 수작업 수정 시간과 AI 수정안 검토·확정까지 시간을 비교 | 완료 업무 유지·선후관계 준수 등 동일한 완료 기준. 선택한 고도화와 직접 연결 |
| 12 | 일정 수정안의 추가 수정 없는 확정 비율 | 조건을 충족하고 전임자가 수정 없이 확정한 안의 수 ÷ 전체 평가 사례 수 | 평가 사례와 검토자 필요. 만족도·정확도 전체를 대변하지 않음 |
| 13 | 일정 조건 준수율 | 완료 업무 유지·선후관계·휴일·기한 등 조건을 모두 충족한 안의 수 ÷ 실행 가능한 평가 사례 수 | 실행 불가능 사례는 정확하게 불가능함을 안내하는지 별도 평가. 기능 검증 성격이 강함 |
| 14 | 기한 내 인수인계 완료율 | 원래 합의한 기한 내 완료 기준을 충족한 사례 수 ÷ 전체 사례 수 | 여러 현장 사례 필요. 기한을 연장해 성공률을 높이지 않음 |

## 3. 선택 이전 제안 — 현재 실행 기준 아님

직접 실험하기 쉬운 조합은 1번 체크리스트 작성 시간, 4번 정보 확인 시간, 9번 질문 정답률, 11번 일정 재조정 시간이다. 준비·사용·정확성·고도화를 각각 평가한다.

체크리스트의 품질을 더 강조한다면 4번 대신 7번을 선택할 수 있다. 실제 인수인계의 시작·완료를 관찰하고 비교할 수 있다면 2번을 대표 지표로 검토한다. 전체 소요 기간은 하위 작업 시간을 더해 추정할 수 없다.

선택 이전에는 목표 수치를 추후 논의하는 안을 검토했으나, 현재는 상단의 네 목표 수치로 확정했다. 기존 시간을 임의로 단정하지 않는다. 단축률은 (기존 방식 시간 − AI 활용 시간) ÷ 기존 방식 시간 × 100으로 계산하며 비교 시간에는 양쪽 모두 동일한 업무 범위를 포함한다. 반복 사용에 따른 학습 효과와 참여자 경험 차이를 기록한다. 후보 선택을 위해 별도의 제품 기능을 추가하지 않는다.
