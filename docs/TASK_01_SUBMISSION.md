# Task 1 — 역량 및 기술 스택 확인

- 수정일: 2026-10-26
- 과제명: 업무 인수인계 Agent
- 상태: 과제 수행을 위한 역량·학습 영역·기술 스택 및 목표 정의

## 1. 현재 보유 역량

- Python 활용 경험: Python 문법을 이해하며, AI 해커톤에서 AI 개발 도구의 도움을 받아 개발한 경험이 있습니다. AI가 해결하지 못한 버그는 직접 코드를 분석해 원인을 찾고 수정할 부분을 제시했습니다. Python 개발은 주로 AI 도구와 함께 진행했습니다.
- 웹·API 개발 경험: React를 여러 프로젝트에서 사용했고, 주로 Java·Spring과 JavaScript로 API를 개발했습니다.
- 검증 경험: 개발한 기능을 직접 실행하여 동작을 확인하고, 문제가 생기면 코드를 분석해 수정했습니다.
- AI/ML 및 LLM 경험: AI/ML은 개인 학습과 실습 수준이며, Llama 등 일부 모델을 개인적으로 사용해본 경험이 있습니다.
- RAG/Agent 구현 경험: 사내 AI Bootcamp에서 LangGraph와 FAISS 기반 RAG를 활용한 개인화 여행 추천 서비스 ‘여행 DNA’를 구현했습니다. 여행지 CSV 데이터를 검색에 활용하고, 사용자 취향 입력부터 여행지 추천과 샘플 코스 생성까지 연결했습니다.
- AI 프로젝트 경험: 부트캠프와 해커톤 경험은 있으나 AI/LLM 관련 실무 프로젝트 경험은 없습니다. 이번 AI Master 부문 과제에서 설계·구현·평가까지 수행하며 역량을 확장하고자 합니다.

## 2. 학습 필요 영역

- 업무 문서 파싱·분할·임베딩과 문서 근거 검색
- LangGraph 기반 업무 추출·검증 흐름과 사용자 검토 연결
- 프롬프트 설계와 체크리스트·답변의 구조화된 응답 처리
- 체크리스트 누락 여부와 문서 기반 답변의 정확성 평가

## 3. 기술 스택 선호도

- 화면 개발: React로 인계자의 문서 등록·체크리스트 검토 화면과 인수자의 확정 내용 조회·진행 현황·질문 화면을 개발합니다.
- 문서 처리: Python·FastAPI로 Word·Excel·PPT의 내용을 추출하고 PPT는 슬라이드 이미지를 분석해 전체 내용을 정리·보관합니다. 업무 데이터는 SQLite, 문서 청크와 벡터는 ChromaDB로 관리합니다.
- AI 처리: LLM으로 체크리스트 생성·내용 재검토·선행 업무 제안을 수행하고, 문서 청크와 원문 근거를 활용합니다. LangGraph로 역할별 처리 흐름을 연결하고 RAG 기반 문서 근거 Q&A를 구성합니다.

## 4. 프로젝트 관심 도메인

- 1순위 도메인: 업무 인수인계 지원
- 2순위 도메인: 사내 업무 지식 관리
- 관심 사유: 분산된 업무 문서를 활용해 인수인계 누락을 줄이고, 후임자가 필요한 업무 지식을 찾도록 지원하는 데 관심이 있습니다.

## 5. 8주 목표 설정

- 기술 목표: 업무 문서 등록부터 체크리스트 생성·검토, 일정 수립·진행 관리, 문서 근거 Q&A까지 연결되는 웹 서비스를 구현합니다. 캘린더 연동·인계자 질문·답변·인수인계 문서 출력 및 서명 기능도 포함해 사용자 흐름을 검증합니다. 고도화로 진행 상황에 따른 일정 수정안을 제안하고 전임자가 검토·확정하는 기능을 구현합니다.
- 비즈니스 목표: 체크리스트 작성 시간과 인수인계 소요 시간을 줄이고, AI 답변을 통해 전임자에게 직접 확인해야 하는 질문을 줄입니다. 진행 관리와 일정 재조정으로 기한 내 인수인계 완료율을 높이는 것을 목표로 합니다. 동일한 업무 범위와 완료 기준으로 기존 방식과 비교·평가합니다.
- 성장 목표: 사내 AI 역량 Lv.2에서 Lv.3으로 성장하는 것을 목표로 합니다. 업무 문제를 AI 과제로 구체화하고 설계·구현·평가 결과를 근거로 설명하는 역량을 기르고자 합니다.
