# 주문 운영 업무 인수인계 — 예시 데이터

이 문서는 개발·검증을 위해 직접 만든 가상의 업무 문서입니다. 실제 회사의 정보가 아닙니다.

## 매일 주문 수집 상태 확인
매일 오전 9시에 주문 운영 화면에서 전날 주문 수집 결과를 확인한다. 실패 건이 있으면 주문 번호와 오류 내용을 기록하고 운영 담당자에게 전달한다.

## 야간 배치 확인
매일 오전 9시 30분에 야간 정산 배치의 종료 상태와 처리 건수를 확인한다. 배치가 실패했다면 중복 정산 가능성이 있으므로 임의로 재실행하지 않고 실패 로그를 정산 담당자에게 전달한다.

## 연계 오류 대응
외부 주문 연계 오류가 발생하면 발생 시각, 요청 식별자, 오류 코드를 확인한다. 재전송 전에는 같은 주문이 이미 저장됐는지 조회한다. 저장된 주문이 있으면 재전송하지 않는다.

## 주간 보고
매주 금요일에 주문 수집 실패 건수와 해결 상태를 정리해 주간 운영 보고서를 작성한다. 미해결 항목은 담당자와 다음 확인 일정을 함께 기록한다.

## 접근 권한 인계
후임자가 주문 운영 화면과 배치 이력 화면을 조회할 수 있는지 확인한다. 접근할 수 없으면 권한 담당자에게 조회 권한을 요청한다. 계정 비밀번호는 문서에 기록하거나 공유하지 않는다.
